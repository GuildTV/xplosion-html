## Changing Teams

The team names are defined in config.js. The initials must be kept to 2 characters, the full names are only used in the controller, so accuracy is not essential.

Team logos are located in the img directory. 

Team colours and logo file paths are defined in /sass/variables.scss. The first colour should be based on the team kit colour, with the second colour having the darken percentage adjusted to look good in the graphic.

After changing all these, the application should be recompiled and can then be run.
